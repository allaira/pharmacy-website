## Вебсайт аптеки

Проєкт охоплює шлях користувача від вибору препарату до оформлення замовлення та пошуку найближчої аптеки:
* **Головна сторінка** — акційний банер, добірки популярних і сезонних товарів, навігація та швидкий пошук.
* **Сторінка товару** — галерея фото, вибір кількості в упаковці з автоматичним оновленням ціни, інструкція та вкладки з характеристиками.
* **Оформлення замовлення** — форма контактних даних із валідацією, вибір міста та способу доставки, оплата й редагування кошика у модальних вікнах.
* **Карта мережі аптек** — пошук за адресою, фільтри (наявність генератора, графік роботи), контакти та зручний перемикач між списком і картою на мобільних пристроях.

## Інструкція з запуску
1. **Завантажте репозиторій:**
   ```bash
   git clone https://github.com/allaira/pharmacy-website.git
   ```
2. **Відкрийте у браузері:**
   * Відкрийте файл `index.html` подвійним кліком у будь-якому браузері;
   * Або запустіть через розширення **Live Server** у VS Code.
3. **Для перегляду мобільної та планшетної версій** відкрийте DevTools (`F12` або `Cmd + Option + I`) та увімкніть режим емуляції пристроїв.
   
## Change Log

### [1.4.0] — Візуальні правки за вимогою замовника та оновлення футера
* **Додавання візуального об'єму :** на вимогу клієнта («прибрати надмірну пласкість макета») додано обʼєм для основних кнопок дій. Об'єм застосовано вибірково, щоб зберегти візуальну ієрархію, читабельність медичного інтерфейсу та уникнути візуального перевантаження сторінки.
* **Доопрацювання підвалу та навігації:** додано активні переходи на соціальні мережі та підправлено верстку футера.

### [1.3.0] — Інтеграція JavaScript-логіки
- **Синхронізація стану (`localStorage`) та робота з DOM:** реалізовано збереження товарів у кошику та списку обраного між усіма сторінками, динамічне створення елементів (`createElement`, `appendChild`) і керування класами (`classList.toggle`).
- **Обробка подій (`click`, `scroll`, `change`, `submit`, `keydown`):** додано інтерактивну галерею на сторінці товару (`product.html`), навігацію по секціях під час прокрутки та миттєвий перерахунок ціни при зміні кількості в упаковці (10/20 шт.).
- **Динамічний контент та валідація форм:** розроблено систему відгуків із перевіркою заповнення полів, підрахунком середнього рейтингу та відмінюванням числівників; реалізовано валідацію контактних даних на сторінці оформлення замовлення (`checkout.html`).
- **Інтерактивна карта аптек (`pharmacies.html`):** підключено бібліотеку Leaflet, налаштовано пошук за адресою та динамічну фільтрацію аптек за графіком роботи й наявністю генератора.
