## Вебсайт аптеки

Проєкт охоплює шлях користувача від вибору препарату до оформлення замовлення та пошуку найближчої аптеки:
* **Головна сторінка** — акційний банер, добірки популярних і сезонних товарів, навігація та швидкий пошук.
* **Сторінка товару** — галерея фото, вибір кількості в упаковці з автоматичним оновленням ціни, інструкція та вкладки з характеристиками.
* **Оформлення замовлення** — форма контактних даних із валідацією, вибір міста та способу доставки, оплата й редагування кошика у модальних вікнах.
* **Карта мережі аптек** — пошук за адресою, фільтри (наявність генератора, графік роботи), контакти та зручний перемикач між списком і картою на мобільних пристроях.

## Інструкція з запуску
1. **Завантажте репозиторій:**
   ```bash
   git clone https://github.com/allaira/pharmacy-website.git)
   ```
2. **Відкрийте у браузері:**
   * Відкрийте файл `index.html` подвійним кліком у будь-якому браузері;
   * Або запустіть через розширення **Live Server** у VS Code.
3. **Для перегляду мобільної та планшетної версій** відкрийте DevTools (`F12` або `Cmd + Option + I`) та увімкніть режим емуляції пристроїв.
